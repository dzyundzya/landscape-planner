# Демонстрационный DXF

`greenplan_demo.dxf` — небольшая синтетическая подоснова для проверки цепочки
загрузка → анализ → настройка → генерация → черновой экспорт. Это не реальный
городской чертёж и не эталон нормативной проверки.

Файл записан как DXF R2010 в метрах. В нём нет XREF, proxy-объектов и неподдерживаемых
типов сущностей.

## Настройка для рабочего демо

В UI выбери единицу `метр` и самый крупный контур площадью 6000 м². Назначь слои:

| Слой | Тип | Роль | Атрибуты |
|---|---|---|---|
| `РАМКА_ГРАНИЦА_УЧАСТКА` | Не учитывать | Линия | — |
| `ЗДАНИЕ` | Здание | Площадной объект | `measurement_reference=exterior_wall`, `building_use=other` |
| `КРАЙ_ДОРОГИ` | Дорога | Линия | `measurement_reference=roadway_edge` |
| `ЭЛЕКТРОКАБЕЛЬ` | Электросеть | Линия | `measurement_reference=utility_outer_surface`, `network_kind=underground_power_cable` |
| `ВОДОПРОВОД` | Водопровод | Линия | `measurement_reference=utility_outer_surface` |
| `СУЩЕСТВУЮЩИЕ_ДЕРЕВЬЯ` | Существующее дерево | Площадной объект | — |
| `ПОДПИСИ` | Не учитвать | Линия | — |

Существующие деревья учитываются по проектным интервалам `tree_tree_distance_m` и
`tree_bush_distance_m`. Для водопровода применяется числовой отступ для деревьев; для кустарников
справочник явно фиксирует отсутствие числового требования и не создаёт нулевую или выдуманную зону.

Все нормативные записи пока сохраняют `needs_verification`, поэтому результат подходит для чернового
демонстрационного экспорта, но не для статуса «проверено по нормам».
