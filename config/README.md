# Конфигурационные справочники

`normative_rules.yaml` содержит правила геометрических отступов от объектов
чертежа. Только проверенные правила с документом, редакцией, пунктом, URL и датой
проверки могут участвовать в подтверждённом результате Validator.

`plant_catalog.yaml` содержит ассортимент деревьев, кустарников и лиан из
предоставленного DOCX. Для каждой позиции сохранены исходное и очищенное название,
раздел ассортимента, ботаническая группа, рекомендации для восьми типов территорий,
примечания и номер строки таблицы. Исходный документ пока не связан с полной
официальной редакцией и URL, поэтому справочник имеет статус
`needs_verification`.

Значение `recommended` означает знак `+` в исходной таблице,
`not_recommended` — знак `-`, `unspecified` — пустую ячейку. Последнее значение
нельзя автоматически считать разрешением. В текущем источнике восемь пустых
значений относятся к одной позиции дополнительного ассортимента.

Справочник растений не заменяет нормативные правила. Он отвечает за выбор
подходящей породы после геометрического размещения. Лианы сохранены для полноты
источника, но не входят в текущий генератор деревьев и кустарников.
