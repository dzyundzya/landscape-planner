# Landscape Planner

Сервис автоматического проектирования городского озеленения по данным DXF.

## Frontend

Интерфейс покрывает создание проекта, загрузку и анализ DXF, подтверждение
настроек, генерацию плана, OpenLayers-preview, ручные правки посадок, повторную
проверку и скачивание экспортного комплекта.

После анализа backend предлагает назначение слоёв с причиной и уровнем
уверенности. Форма позволяет искать и массово сопоставлять слои, скрывает
действительно неиспользуемые записи и отдельно показывает объекты внутри BLOCK.
Границу можно выбрать среди крупнейших замкнутых полилиний на локальной карте.
Все предложения требуют подтверждения при сохранении конфигурации.

Интерфейс запоминает ID открытого проекта и после обновления страницы восстанавливает
последний файл, анализ, конфигурацию и план из PostgreSQL. На первом шаге также можно
выбрать ранее созданный проект.

Для разработки запустите backend на `127.0.0.1:8000`, затем:

```bash
cd frontend
npm install
npm run dev
```

Vite откроет интерфейс по адресу `http://127.0.0.1:5173/static/` и проксирует
запросы `/api` в FastAPI.

Production-сборка проверяется командой:

```bash
cd frontend
npm run build
```

Сборка попадает в игнорируемый каталог `app/static`. Если этот каталог существует,
FastAPI раздаёт интерфейс через `/static/` и перенаправляет корневой маршрут `/` на
него.

## Большие DXF

По умолчанию принимаются исходники до 300 МБ, а результат экспорта — до 500 МБ.
Загрузка и публикация файлов выполняются потоково. Worker остаётся единственным и
последовательным; для каждого тяжёлого задания он журналирует размер исходника,
время выполнения и пиковый RSS процесса.

Preview ограничен 2 000 исходных объектов, 2 000 нормативных зон и общим бюджетом
около 200 000 координат. Геометрия карты может упрощаться с погрешностью от 0,1 м,
но расчёт, Validator и итоговый DXF используют исходную геометрию. Лимиты задаются
переменными `MAX_UPLOAD_SIZE_BYTES`, `MAX_ARTIFACT_SIZE_BYTES`,
`PREVIEW_SIMPLIFY_TOLERANCE_M`, `PREVIEW_MAX_OBJECTS`,
`PREVIEW_MAX_RESTRICTIONS` и `PREVIEW_MAX_COORDINATES`.

## LangChain-агент

Маршрут `POST /api/projects/{project_id}/agent/messages` и панель помощника в UI
используют `langchain.agents.create_agent`. Агент получает только краткие сводки
проекта и семь инструментов: состояние проекта, анализ, предложения по слоям,
генерацию, статус задачи, объяснение посадки и экспорт. CAD-расчёты выполняют
обычные сервисы и worker.

По умолчанию агент отключён. Для OpenAI добавьте в `.env`:

```dotenv
AGENT_ENABLED=true
LLM_PROVIDER=openai
LLM_MODEL=<модель-с-поддержкой-tool-calling>
LLM_API_KEY=<ключ>
ALLOW_EXTERNAL_LLM=true
```

Для локального OpenAI-compatible сервера задайте `LLM_PROVIDER=openai_compatible`,
`LLM_BASE_URL=http://127.0.0.1:.../v1` и требуемый сервером `LLM_API_KEY`.
Loopback-подключение не требует `ALLOW_EXTERNAL_LLM=true`. После изменения `.env`
перезапустите FastAPI; worker перезапускать не требуется.
